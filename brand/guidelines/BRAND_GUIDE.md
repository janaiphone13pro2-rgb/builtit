# BuiltIt Brand Identity

## Brand Essence

**Tagline:** We Build Digital Presence That Converts.

**Mission:** Help Egyptian businesses and students establish professional digital presence without subscriptions or templates — just craft.

**Personality:** Bold, focused, fast, local, professional.

---

## Logo

### Primary Logo
The BuiltIt logo consists of the wordmark "BuiltIt." with the "It." portion highlighted in mint green.

**Double L Meaning:** The double L represents building blocks — layers of work stacking together.

**Mint "It.":** The highlighted "It." emphasizes that we build *it* — whatever digital presence you need.

### Logo Versions

| Version | Usage |
|---------|-------|
| **Primary** (mint "It" on dark) | Dark backgrounds, main brand usage |
| **Reversed** (mint "It" on white) | Light backgrounds, print materials |
| **Monochrome White** | Single-color applications |
| **Monochrome Black** | Light backgrounds when color unavailable |

### Clear Space
Maintain minimum clear space around the logo equal to the height of the period/dot.

### Minimum Size
- Digital: 120px width
- Print: 40mm width

## Color Palette

### Primary Colors

| Color | Hex | RGB | Usage |
|-------|-----|-----|-------|
| **Background** | `#0A0A0A` | rgb(10, 10, 10) | Page backgrounds, dark UI |
| **Foreground** | `#FFFFFF` | rgb(255, 255, 255) | Text, icons |
| **Mint** | `#4EF2AD` | rgb(78, 242, 173) | Primary accent, CTAs, highlights |
| **Mint Glow** | `rgba(78,242,173,0.18)` | rgba(78, 242, 173, 0.18) | Soft highlights and hover states |

### Secondary Colors

| Color | Hex | Usage |
|-------|-----|-------|
| **Card BG** | `rgba(255,255,255,0.03)` | Card backgrounds |
| **Border** | `rgba(255,255,255,0.08)` | Subtle borders |
| **Muted** | `rgba(255,255,255,0.6)` | Secondary text |
| **Mint 10%** | `rgba(78,242,173,0.1)` | Icon backgrounds |

### Color Usage Rules

1. **Mint is precious** — use sparingly for maximum impact
2. **Mint anchors action** — primary conversion buttons and ownership highlights use mint
3. **White is 70% of UI** — text, icons, subtle elements
4. **Background stays dark** — our signature look

## Typography

### Headings: Bebas Neue

- **Font:** Bebas Neue (Google Fonts)
- **Weight:** 400 (regular)
- **Case:** UPPERCASE
- **Tracking:** Wide letter-spacing (0.05em)
- **Sizes:**
  - Hero: 96px / 6rem
  - H1: 72px / 4.5rem
  - H2: 60px / 3.75rem
  - H3: 48px / 3rem

### Body: DM Sans

- **Font:** DM Sans (Google Fonts)
- **Weights:** 400 (regular), 500 (medium), 700 (bold)
- **Case:** Sentence case
- **Line Height:** 1.6 for body, 1.2 for headings
- **Sizes:**
  - Large: 18px / 1.125rem
  - Base: 16px / 1rem
  - Small: 14px / 0.875rem
  - XS: 12px / 0.75rem

### Typography Patterns

```
Section Label: 12px, uppercase, tracking-[0.2em], mint color
Headline: Bebas Neue, uppercase, wide tracking
Body: DM Sans, white/70% opacity, max-width 65ch
```

## Visual Language

### Shapes

- **Border Radius:** 4px (consistent across all UI elements)
- **Cards:** 1px border with subtle transparency
- **Icons:** Inside 12px padding containers

### Spacing System

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Tight gaps |
| sm | 8px | Icon gaps |
| md | 16px | Component padding |
| lg | 24px | Section gaps |
| xl | 32px | Card padding |
| 2xl | 48px | Major sections |
| 3xl | 64px | Section padding |
| Section | 120px | Vertical section spacing |

### Grid

- **Container:** max-width 1280px (7xl), centered
- **Columns:** 12-column implicit grid
- **Gutter:** 24px (gap-6)
- **Padding:** 24px mobile, 32px desktop

## Photography & Imagery

### Style

- High contrast
- Architectural or tech-focused
- Egyptian context when possible
- Desaturated except for mint accents

### Treatment

- Overlay: gradient from transparent to `#0A0A0A` at bottom
- Opacity: 80-90% for backgrounds
- Hover: scale 1.05 with smooth transition

## UI Components

### Buttons

**Primary CTA (Mint)**
- Background: `#4EF2AD`
- Text: black, uppercase, bold
- Padding: 16px 32px
- Radius: 4px
- Hover: darken 10%

**Secondary (Mint)**
- Background: `#4EF2AD`
- Text: black, uppercase, bold
- Padding: 16px 32px
- Radius: 4px
- Hover: darken 10%

**Ghost**
- Border: 1px `rgba(255,255,255,0.2)`
- Text: white
- Hover: `rgba(255,255,255,0.05)` background

### Cards

- Background: `rgba(255,255,255,0.03)`
- Border: 1px `rgba(255,255,255,0.08)`
- Radius: 4px
- Padding: 24px or 32px
- Hover: mint border glow (subtle)

### Inputs

- Background: `#0A0A0A`
- Border: 1px `rgba(255,255,255,0.08)`
- Focus: mint border
- Radius: 4px
- Padding: 12px 16px

## Motion & Animation

### Principles

1. **Purposeful** — every animation serves UX
2. **Smooth** — ease-in-out curves, never jarring
3. **Fast** — 200-500ms durations
4. **Respectful** — reduced-motion support

### Patterns

| Animation | Duration | Easing |
|-----------|----------|--------|
| Fade Up | 700ms | ease-out |
| Stagger | 100ms delay | ease-out |
| Hover Scale | 300ms | ease-in-out |
| Count Up | 1500ms | ease-out |
| Page Transition | 300ms | ease-in-out |

## Voice & Tone

### We Are

- Direct and clear
- Confident but not arrogant
- Professional yet approachable
- Proudly Egyptian

### We Say

- "We build" — not "we create" or "we design"
- "Digital presence" — not "websites" alone
- "Converts" — focused on results

### We Don't Say

- "Solutions" (too generic)
- "Leverage" (buzzword)
- "Synergy" (buzzword)
- "Best-in-class" (claim without proof)

### Writing Style

- Short sentences
- Active voice
- Second person ("you")
- No exclamation points (except CTAs)

## Usage Dont's

1. Don't stretch or distort the logo
2. Don't change the logo colors
3. Don't rotate the logo
4. Don't add effects (shadows, glows) to the logo
5. Don't place the logo on busy backgrounds
6. Don't use the mint color for large text areas
