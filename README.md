# our-Builtit-

A React + Vite portfolio site for BuiltIt with two pages:

- Landing page at `/`
- Portfolio page at `/portfolio.html`

## Tech Stack

- React 18
- Vite 5
- CSS

## Getting Started

```bash
npm install
npm run dev
```

Open the local URL shown by Vite, usually:

```text
http://localhost:5173/
```

Portfolio page:

```text
http://localhost:5173/portfolio.html
```

## Scripts

```bash
npm run dev
npm run build
npm run preview
```
